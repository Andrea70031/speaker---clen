# Native iOS build

This repository includes a native SwiftUI proof-of-concept under `SonicMD/` and `SonicMD.xcodeproj/`.

Planned stack:
- SwiftUI
- AVFoundation
- AVAudioEngine
- AVAudioSession
- Accelerate

The native build is intended for cloud compilation via Codemagic and later TestFlight distribution.

The Response Index remains an experimental comparative metric and must not be presented as a certified hardware diagnostic value.
